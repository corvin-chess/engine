Planned Rust crate for Corvin's own chess engine. Intended surfaces: bitboard search, handcrafted evaluation, NNUE inference trained only on Corvin self-play data from [engine-train](https://github.com/corvin-chess/engine-train), UCI over stdin, and a WASM worker build for [web](https://github.com/corvin-chess/web) analysis. Move generation depends on [chess-core](https://github.com/corvin-chess/chess-core). No third-party engine or weights. Strength claims require SPRT against the previous version. No engine source is in this repository yet.
